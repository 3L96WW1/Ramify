# 麻 / Ramify

Minecraft **1.21.1** / Fabric 模组：纤维植物、绷带与草药。

| 项 | 值 |
|---|---|
| Minecraft | **1.21.1** |
| 加载器 | Fabric（Loader ≥ 0.16，需要 Fabric API） |
| Java | **21** |
| 模组 id | `ramify` |
| 版本 | `0.2.0-beta+1.21.1` |

## 内容

### 纤维植物
- **麻**：草原 / 草甸 / 普通森林 / 针叶林少量生成，不可种植（不可再生）；始终像玫瑰丛一样两格高、上下同步破坏，破坏时间约 0.5 秒；打掉掉 1~3 **麻叶**，另有小概率掉麻纤维
- **黄麻**：白桦林与沼泽少量生成，不可种植，两格高，掉黄麻叶，小概率掉麻纤维
- **剑麻**：热带草原少量生成，不可种植，掉剑麻叶，小概率掉麻纤维
- **寒麻**：雪原/雪林等雪地群系少量生成，冰蓝白色贴图，不可种植，掉落与普通麻一致
- **高山亚麻**：在 Y 120~220 生成，所有非雪地群系；深绿色麻贴图带紫色花瓣点缀；只长在草地/泥土，不能长在石头上；掉落 1~2 麻叶 + 2~6 麻纤维
- **麻纸**：3 麻纤维 → 3 麻纸，可替代原版纸参与书、地图、烟花、旗帜图案等合成

### 医疗
- **绷带**：3 麻纤维 + 3 麻叶 + 3 麻纸 → 2 个；按住使用 1.6 秒，回 4 点血、抗性提升 5 秒、移除一个负面效果
- **抗感染药**：黄麻叶 + 麻叶 + 糖；立刻清除负面效果，并在 4 分钟内持续压制
- **肾上腺素**：剑麻叶 + 麻叶 + 糖；力量、抗性提升、速度 II 各 2 分 30 秒

### 食物与植物
- **草莓丛**：1.5 格高，无幼株阶段（生成即成熟），不可再生（不掉落丛）；白桦林、草甸、森林、向日葵平原少量生成，河岸/樱花林/黑森林/沼泽/针叶林更低概率；右键采摘后过一段时间重新结果
- **玉米**：野外低概率生成；玉米本身不能放置，**玉米种子可以种在耕地或草方块**；成熟后右键采摘（不破坏植株，回落一阶段继续长），也可直接打掉；可食用，熔炉/烟熏炉/营火可烤成**烤玉米棒**（回复 3 格饱食度）
- **草菇**：森林中低概率生成
- **松茸**：所有雪地群系（雪原、雪林、冰刺之地等）低概率生成
- **油菜花**：森林、草原与丛林低概率生成，破坏得到**油菜**；2 油菜 + 碗 → 油菜汤（9 秒生命恢复 + 温暖），油菜 + 浆果 + 猪肉 → 生烤串
- **美味的蘑菇汤**：草菇 + 松茸 + 油菜 + 木碗，附带生命恢复、抗性提升与速度；所有汤喝完返还空碗

### 防御
- **木刺**：3px 高的钉板，地面生物踩上去受伤并被推开

### 生物
- **梭子蟹**：沙滩刷新（河边少量），横向行走；击杀掉骨粉和生梭子蟹；钓鱼也有概率钓到
- **龙虾**：沙滩/河边少量刷新；钓鱼可钓到；击杀掉骨粉和生龙虾
- 生梭子蟹食用：中毒 3 秒 + 虚弱 10 秒
- 熟梭子蟹（熔炉）：食用获得抗性提升 1 分钟；首次食用获得成就「第一个“吃螃蟹的人”」
- 首次获得生梭子蟹获得成就「卡尼卡尼？」（时间停止吧，你是多么的美丽）

### 创造专属方块
- 麻、黄麻、剑麻、寒麻、高山亚麻、草莓丛、玉米植株都有仅创造模式可拿的方块物品；生存无法获得，放置后正常生长/结果

### 村民交易
- 农民（1 级）收购 16 麻叶 / 4 麻纤维 / 8 玉米 → 绿宝石
- 农民（2 级）出售 4 玉米种子 → 1 绿宝石

### 成就
- **以麻敛血**：第一次使用绷带
- **Blight...the corn will die...soon**：收获第一根玉米
- **Non Terrae Plus Ultra**：第一次注射肾上腺素

## 构建

```bash
./build.sh build      # 产物在 build/libs/
./build.sh runClient  # 开发客户端
```

`build.sh` 会把 Gradle 用户目录固定到项目内的 `.gradle-home/`，避免 `~/.gradle` 不可写的问题。

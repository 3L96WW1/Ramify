## 构建

```bash
cd ~/Documents/ramify
./build.sh build       # 产物在 build/libs/
./build.sh runClient   # 开发客户端
./build.sh runServer   # 开发服务端
```

`build.sh` 会把 Gradle 用户目录固定到项目内的 `.gradle-home/`，并默认使用 `--no-daemon`，避免当前环境的 Gradle daemon 崩溃。

如果 Gradle daemon 异常退出：

```bash
./build.sh --stop
rm -rf .gradle-home/daemon
./build.sh build --no-daemon
```

## 纤维植物

| 植物 | 生成 | 说明 |
|---|---|---|
| **麻** | 草原、向日葵平原、草甸、森林、花林、针叶林，Y<120 | 两格高，上下同步破坏，约 0.5 秒 |
| **黄麻** | 白桦林、原始白桦林、沼泽、红树林沼泽，Y<120 | 两格高 |
| **剑麻** | 金合欢/热带草原群系，任意高度 | 金合欢群系只生成剑麻 |
| **寒麻** | 雪原、雪林、雪滩、冰刺之地等雪地群系，Y<120；Y220 以上极少量 | 冰蓝白贴图 |
| **高山亚麻** | Y120~220，所有非雪地群系（金合欢除外）；Y220 以上极少量 | 深绿色带紫色花瓣，只长草地/泥土 |

- 普通麻类（麻、黄麻、寒麻）有严格的 `Y<120` 高度过滤
- 高山亚麻使用 `Y120~220` 高度范围，220 以上另有极低概率变体
- 麻类都不可种植；破坏掉落对应麻叶和少量麻纤维
- 高山亚麻：1~2 麻叶 + 2~6 麻纤维
- **麻纸**：3 麻纤维横排 → 3 麻纸，可替代原版纸参与书、地图、烟花、旗帜图案等 8 种配方

## 食物与农业

- **玉米**：野外低概率生成；玉米本身不能放置；**玉米种子**可种在耕地或草方块上。成熟后右键采摘会回落到前一阶段继续生长，也可直接打掉。
- **草莓丛**：1.5 格高，无幼株阶段，不可再生；打掉获得 2~4 草莓。
- **草菇**：森林低概率生成。
- **松茸**：雪地群系低概率生成。
- **油菜花**：森林、草原、丛林低概率生成，破坏获得**油菜**。
- **美味的蘑菇汤**：草菇 + 松茸 + 油菜 + 木碗。
- **油菜汤**：2 油菜 + 木碗，9 秒生命恢复 + 温暖。
- **生烤串**：油菜 + 甜浆果 + 生猪排。
- **草莓小蛋糕**：右上糖、中排鸡蛋 + 甜浆果、下排两小麦。
- **蜂蜜浆果小蛋糕**：上排甜浆果 + 糖、中排鸡蛋 + 蜂蜜瓶、下排两小麦。
- **玉米小蛋糕**：上排玉米 + 糖、中排鸡蛋 + 蜂蜜瓶、下排两小麦。
- 所有汤喝完返还空碗。

## 生物

### 梭子蟹

- 沙滩/雪滩权重 100，河流/冻河权重 20
- 横向行走
- 击杀掉落骨粉 1~2 + 生梭子蟹
- 钓鱼有概率钓到生梭子蟹
- 3 点生命；空手攻击会触发荆棘反伤
- 生食：中毒 3 秒 + 虚弱 10 秒
- 熟食：抗性提升 1 分钟

### 龙虾

- 沙滩/雪滩权重 40，河流/冻河权重 15，沼泽/红树林沼泽权重 25
- 独立模型：长身体、尾扇、触须、大钳、步足
- 击杀掉落骨粉 + 生龙虾
- 钓鱼有概率钓到生龙虾
- 生食：中毒 3 秒 + 虚弱 10 秒
- 熟食「龙虾大餐」：生命提升 II + 强心（额外 +3 颗心），共 +7 颗心，持续 60 秒

## 蔷薇丛

- 野外花林/草原/草甸/森林/白桦林/黑森林/樱花林小概率生成
- 1 格高，带红色蔷薇
- 打掉未成熟蔷薇丛掉落蔷薇种子；成熟打掉获得 1 种子 + 1 蔷薇
- 蔷薇种子只能种在耕地上，可用骨粉催熟
- 蔷薇可对玩家右键使用：送入对方背包并出现心形粒子

## 户外烧烤架

- 3 格宽、1 格底座、1.5 格高模型
- 合成：工作台第三排左铁锭、中熔炉、右熔炉
- 右键任意部位打开 GUI
- GUI 内容：
  - 十字形 4 个原料格（中间空）
  - 2 个燃料格
  - 右侧 8 个成品槽，显示成品名称
  - 熔炉式进度条 + 燃料条
  - 右下角 3×3 工作台面板
  - 右上角「配方」按钮，可滚动查看全部配方
- 1 个燃料烤 4 个，速度同烟熏炉（100 tick/个）
- 牛奶桶/水桶制作后会返还空桶
- 4 个原料都不匹配配方时，产出负面效果**迷之炖菜**（中毒/反胃/饥饿/虚弱）

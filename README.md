# 麻 / Ramify

Minecraft **1.21.1** / Fabric 模组：麻、绷带与野外植物。

| 项 | 值 |
|---|---|
| Minecraft | **1.21.1** |
| 加载器 | Fabric（Loader ≥ 0.16，需要 Fabric API） |
| Java | **21** |
| 模组 id | `ramify` |
| 版本 | `0.1.0-beta+1.21.1` |

## 内容

- **麻**：野外稀疏生成（草地），不可再生；打掉掉 1~3 麻纤维
- **绷带**：按住使用 1.6 秒 —— 回 4 点血、抗性提升 5 秒、移除一个负面效果，伴随窸窣声
- **抗感染药**：清除所有负面效果
- **肾上腺素**：速度 II 30 秒 + 力量 I 15 秒
- **草莓丛**：右键采摘，会重新生长
- **玉米**：野外稀疏生成 / 种在耕地；可食用
- **木刺**：地面生物踩上去受伤并被推开
- 成就：**以麻敛血**（第一次使用绷带）

## 构建

```bash
./gradlew build      # 产物在 build/libs/
./gradlew runClient  # 开发客户端
```

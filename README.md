# 麻 / Ramify

Minecraft **1.21.1** / Fabric 模组：纤维植物、绷带与草药。

| 项 | 值 |
|---|---|
| Minecraft | **1.21.1** |
| 加载器 | Fabric（Loader ≥ 0.16，需要 Fabric API） |
| Java | **21** |
| 模组 id | `ramify` |
| 版本 | `0.2.0-beta+1.21.1` |

## 内容

### 纤维植物
- **麻**：草原 / 草甸生成，始终像玫瑰丛一样两格高、上下同步破坏，破坏时间约 0.5 秒；打掉掉 1~3 **麻叶**，另有小概率掉麻纤维
- **黄麻**：白桦林少量生成，两格高，掉黄麻叶，小概率掉麻纤维
- **剑麻**：热带草原少量生成，掉剑麻叶，小概率掉麻纤维
- **麻纸**：3 麻纤维 → 3 麻纸，可替代原版纸参与书、地图、烟花、旗帜图案等合成

### 医疗
- **绷带**：3 麻纤维 + 3 麻叶 + 3 麻纸 → 2 个；按住使用 1.6 秒，回 4 点血、抗性提升 5 秒、移除一个负面效果
- **抗感染药**：黄麻叶 + 麻叶 + 糖；立刻清除负面效果，并在 4 分钟内持续压制
- **肾上腺素**：剑麻叶 + 麻叶 + 糖；力量、抗性提升、速度 II 各 4 分钟

### 食物与植物
- **草莓丛**：右键采摘，会重新生长
- **玉米**：野外低概率生成，甘蔗式两格高、上下同步破坏；野生玉米长在草地，玩家用玉米种子只能种在耕地，打到的玉米也不能放到草地上；可食用，熔炉/烟熏炉/营火可烤成**烤玉米棒**（回复 3 格饱食度）
- **草菇**：森林中低概率生成
- **松茸**：所有雪地群系（雪原、雪林、冰刺之地等）低概率生成
- **油菜花**：森林与草原低概率生成；2 油菜花 + 碗 → 油菜汤，油菜花 + 浆果 + 猪肉 → 生烤串
- **美味的蘑菇汤**：草菇 + 松茸 + 油菜花 + 木碗，附带生命恢复、抗性提升与速度

### 防御
- **木刺**：3px 高的钉板，地面生物踩上去受伤并被推开

### 成就
- **以麻敛血**：第一次使用绷带
- **Blight...the corn will die...soon**：收获第一根玉米
- **Non Terrae Plus Ultra**：第一次注射肾上腺素

## 构建

```bash
./build.sh build      # 产物在 build/libs/
./build.sh runClient  # 开发客户端
```

`build.sh` 会把 Gradle 用户目录固定到项目内的 `.gradle-home/`，避免 `~/.gradle` 不可写的问题。
